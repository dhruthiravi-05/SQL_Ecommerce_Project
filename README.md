E-Commerce Sales Analysis Using SQL

1. Project Overview
This project focuses on analysing e-commerce sales data using SQL to understand business performance and customer purchasing patterns.

2. Objective
- Calculate total sales revenue.
- Identify top-selling products.
- Analyse category-wise revenue.
- Understand customer purchasing behaviour.
- Compare sales performance across cities.

3. Tools Used
- MySQL Server
- MySQL Workbench
- SQL

4. Dataset Description
The project contains 10 sample order records with the following columns:

- Order_ID
- Customer_Name
- Product
- Category
- Quantity
- Price
- Order_Date
- City
- Status

5. SQL Concepts Used
- SELECT and WHERE
- ORDER BY
- Aggregate Functions (COUNT, SUM, AVG)
- GROUP BY and HAVING
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions (ROW_NUMBER, DENSE_RANK)
- PARTITION BY

6. Key Findings
- Total orders: 10
- Completed orders: 8
- Completed-order revenue: ₹2,10,000
- Highest-revenue category: Electronics
- Highest-revenue product: Laptop
- Top-selling product by quantity: Headphones

7. Conclusion
This project helped me understand how SQL can be used to cleanly retrieve, filter and analyse sales data and generate meaningful business insights.
